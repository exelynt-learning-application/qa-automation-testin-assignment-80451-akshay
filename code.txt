# API Testing with Postman

## 1. Objective

The objective of this assignment is to perform API testing using Postman. Different HTTP methods such as **GET, POST, PUT, and DELETE** are tested, and the responses are validated using status codes, response body, response time, and assertions.

# 7. Postman Test Scripts / Assertions

At least five assertions are required.

### Assertion 1 – Status Code

```javascript
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});
```

### Assertion 2 – Response Time

```javascript
pm.test("Response time is less than 2000ms", function () {
    pm.expect(pm.response.responseTime).to.be.below(2000);
});
```

### Assertion 3 – Response Body

```javascript
pm.test("Response body is not empty", function () {
    pm.expect(pm.response.text()).to.not.be.empty;
});
```

### Assertion 4 – Response Contains ID

```javascript
pm.test("Response contains ID", function () {
    var jsonData = pm.response.json();
    pm.expect(jsonData).to.have.property("id");
});
```

### Assertion 5 – Content Type

```javascript
pm.test("Response is JSON", function () {
    pm.expect(pm.response.headers.get("Content-Type")).to.include("application/json");
});
```
